# Security Policy

Do not publish production credentials, certificates, private keys, hostnames, IP addresses, tenant IDs, logs containing personal data, or customer configurations.

Report suspected issues privately through [SARABEL Informatika](https://sarabelinformatika.hu). Include the affected file, impact, reproduction steps, and a safe remediation proposal. Do not open a public issue for an exploitable vulnerability.

The examples use placeholders and the scripts are designed to be read-only. Operators remain responsible for testing, change control, backup, and rollback.
