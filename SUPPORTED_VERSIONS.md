# Supported Versions

| Guide release | Windows Server focus | Status |
|---|---|---|
| 1.x | Windows Server 2025 and 2022 | Supported |
| 1.x | Windows Server 2019 | Compatibility guidance only |
| 1.x | Windows Server 2016 | Migration priority; extended support ends January 12, 2027 |

Use currently supported clients, FSLogix builds, security updates, and RDS CALs appropriate to the server version.
